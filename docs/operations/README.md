# Operations documents

Runbook cho setup môi trường, MJLab, Isaac Lab, MuJoCo bridge, DDS, network,
rosbag và vận hành. `practice/` là bài hướng dẫn theo lộ trình; báo cáo kết quả
được đặt ở `reports/` ở root để tách khỏi SOP sống.

## Teleop R1

- [`r1_quest3_teleop_hardware.md`](r1_quest3_teleop_hardware.md) — chạy Quest
  teleop tay/đầu trên robot thật, robot treo trên giá. Điều kiện bắt buộc, trình
  tự, giới hạn đang áp, cách dừng và sự cố thường gặp.
- [`r1_quest3_teleop_sim.md`](r1_quest3_teleop_sim.md) — đường mô phỏng.
