# D001 runs

Bằng chứng bất biến, một thư mục cho mỗi lần chạy. Tên thư mục là run id có tiền
tố `d001_`, cấp bằng `evidence/run_id.py`; không đặt tay.

Nội dung của `runs/` bị `.gitignore` chặn (`experiments/**/runs/*`), trừ chính
file README này. Ảnh dataset không đi vào lịch sử git.

Không sửa một run sau khi nó đã ghi xong. Chạy lại thì tạo run mới.
