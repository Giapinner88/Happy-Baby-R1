# P001 — archived R1 velocity-task port pilot

P001 preserves the original R1 `Unitree-R1-Velocity` port evidence. It is not
an active protocol, not a standing baseline, and its exported policy must not
be promoted or deployed.

The completed latest run is
`P001_velocity_port_pilot_20260728T025327Z`. Training evidence is complete,
but the training analysis found dominant orientation termination and no
independent fixed replay was recorded. See [analysis.md](analysis.md).

[archive_migration.json](archive_migration.json) maps the former identifier
and paths to this archive without editing generated checkpoint, video, event,
or export bytes. Use [I002 nominal stable standing](../I002_nominal_stand/)
for all new standing work.
