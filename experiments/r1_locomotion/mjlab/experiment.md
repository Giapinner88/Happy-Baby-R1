# R1 MJLab Locomotion

This experiment owns new MJLab R1 locomotion runs launched through the
workspace training entry point. The experiment definition, resolved run
configuration, provenance, logs, diagnostics, metrics, checkpoints, and export
manifests belong here.

The current bounded pilot is [M001 planar stand and slow walk](M001_flat_stand_walk/).

`legacy_inventory.json` records historical paths purged during the data-area
reset. Those entries are not available as local evidence and must not be
silently promoted.
