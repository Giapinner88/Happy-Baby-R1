# T002 — Arm/wrist workspace and self-collision probe

T002 owns the simulation-only workspace reachability sweep and the controlled
self-collision A/B probe. It uses the editable preset in
[`config/r1_t002_workspace.json`](config/r1_t002_workspace.json), the case
selection in [`metadata/evidence_catalog.json`](metadata/evidence_catalog.json),
and immutable evidence in [`runs/`](runs/).

The observed no-self-collision result is functional simulation evidence, not a
claim that the R1 collision geometry is fixed. T003 may use only the selected
no-self-collision workspace records declared in its own configuration.

## Retained execution inventory

| `t002_collide_20260802T120409Z` | self collisions enabled | retained controlled A/B comparison |
| `t002_nocollide_20260802T120645Z` | self collisions disabled | selected functional workspace source |

The identical target grid is the independent variable for the A/B pair. With
self collisions enabled, the current R1 asset blocks the relevant arm motion;
disabling them gives a functional simulation condition but is explicitly a
workaround. Do not infer a collision-free robot workspace from the selected
run.

The no-collision execution attempted 128 declared targets: 50 converged and
78 did not under the swept seed. Offline re-solving the 78 non-converged targets
with a larger iteration budget and larger solver step changed none; 10 did
converge from a fresh zero seed. Thus the retained record distinguishes 68
seed-independent non-convergences, 10 seed-dependent targets, and 50 reached
targets. These counts describe this declared solver/configuration, not a
hardware reachability envelope.

## Run T002 again

Run from the repository root with `unitree_sim_env`; omit `--output-dir` to
allocate a new immutable directory under `T002/runs/`:

```bash
conda run --no-capture-output -n unitree_sim_env python \
  scripts/teleop/run_r1_t002_workspace.py --no-self-collisions --headless
```

Use `--self-collisions` only as the explicitly declared comparison condition.
The runner refuses to overwrite a supplied output directory.
