# T003-A — Nominal rate-limited trajectory tracking

## Question and scope

Can the right arm/wrist track the declared minimum-jerk trace under valid input
only? This protocol contains **no** deadman, stale-packet or sequence injection.
It isolates normal tracking from intentionally abrupt fail-closed behavior.

The fixed command-target envelopes are `qdot=1.0 rad/s`, `qddot=2.0 rad/s²`,
and jerk `=10.0 rad/s³`. They are exploratory simulation values, not hardware
safety limits. The right-arm waypoints are traceable to the selected no-self-
collision T002 records. Self collisions remain disabled because T002 established
that the current USD blocks the arm when enabled.

## Execute

```bash
conda run --no-capture-output -n unitree_sim_env \
  python scripts/teleop/run_r1_t003_trajectory.py --case-id nominal --headless
```

The allocated run id starts `t003_a_nominal_`. It writes one immutable case
record, including `trajectory.csv`, `metrics.json`, `verification.json`, video,
and event log. A nonzero lower-body/base dispatch, missing trace, non-converged
waypoint, or target-envelope violation invalidates the run.
