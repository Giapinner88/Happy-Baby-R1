# T003 — Rate-limited arm/wrist replay

T003 owns replay of selected T002 targets through the simulation-only R1 arm
controller. It is split deliberately:

- [T003-A](T003-A.md): nominal trajectory tracking only.
- [T003-B](T003-B.md): one fail-closed hold transition per run.
- [Legacy combined runs](T003-legacy.md): retained but not selected.

The active case matrix is
[`config/r1_t003_case_matrix.json`](config/r1_t003_case_matrix.json); editable
case selection lives in [`metadata/evidence_catalog.json`](metadata/evidence_catalog.json).
Every execution is immutable under [`runs/`](runs/). Figures assembled for a
durable result belong in [`figures/`](figures/README.md), not copied from raw
run evidence.
