# T001 — Quest transport and live bridge

T001 owns the two connection gates for the Quest 3 teleoperation path. It is
simulation-only: it never authorizes a hardware command.

- [T001-A](T001-A.md) captures Quest transport telemetry only.
- [T001-B](T001-B.md) evaluates the live project bridge into Isaac Sim.
- [`config/`](config/) contains the editable project bridge preset.
- [`metadata/evidence_catalog.json`](metadata/evidence_catalog.json) records the
  editable case selection; per-run provenance remains immutable in [`runs/`](runs/).
- [`figures/`](figures/README.md) is reserved for reproducibly generated summaries.

Each new evidence run is allocated under `T001/runs/`. The selected T001-B run
is simulation evidence only; it does not prove hardware readiness.
