# T006 — Bilateral workspace and ownership

T006 is an executable bounded **kinematic screening** experiment. It proceeds
on the user's provisional T005 gate assumption, without changing T005's
selection or scientific outcome. The three fixed cases are mirror,
asymmetric and inward/midline approach; their protocol is declared in
[`config/r1_t006_bilateral_kinematic_cases.json`](config/r1_t006_bilateral_kinematic_cases.json).

Run from the repository root:

```bash
python3 scripts/teleop/run_r1_t006_bilateral.py --case-id all
```

Every case gets a fresh immutable `runs/t006_<case-id>_<UTC>/` directory with
the bilateral target/solution trace, arm ownership audit, metrics, two-run
deterministic repeatability check, resolved configuration and source hashes.
Repeat only one case with `--case-id mirror_t003`, `asymmetric_t003` or
`inward_t002_grid`. The runner is CPU-only and opens no Quest, Isaac Lab,
DDS, ROS, Unitree SDK or hardware command channel.

The pass rule is deliberately narrow: both arms must solve every simultaneous
target without a joint clamp, and the ten arm joints must be complete in and
disjoint within ownership. It records wrist-endpoint separation as a diagnostic
only. The current R1 USD self-collision defect means T006 cannot establish a
collision-free workspace or generate valid contact events/video while
functional arm runs require self-collisions disabled. Those fields are marked
`inconclusive`, not treated as zero collisions.

The first run therefore supplies evidence for the bilateral IK/ownership part
of T006, but does not close the collision component or promote a live Quest
bilateral trace. A physics-valid collision repair/validation is a separate
follow-up after the USD defect is resolved.

## Initial kinematic outcome — 2026-08-11

The complete selected three-case inventory is in
[`metadata/initial_kinematic_selection.json`](metadata/initial_kinematic_selection.json).
All 12 simultaneous target pairs converged without a solved joint clamp. The
audited ten arm joints were complete in upper-body ownership, had no left/right
or lower-body overlap, and the minimum reported wrist-endpoint separation was
0.33331028 m. This is a direct deterministic IK/ownership observation only.

Collision/contact remains **inconclusive**: a wrist-endpoint distance does not
represent geometry clearance, while the known USD self-collision defect prevents
a collision-valid functional arm run. No video is applicable to this CPU-only
kinematic execution; the missing collision events and video are explicitly
recorded in every run's completeness record.
