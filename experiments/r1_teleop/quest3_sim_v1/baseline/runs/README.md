# Immutable baseline runs

Run mới dùng ID `baseline_upstream_<UTC>`. Một run canonical chỉ hoàn tất khi
`artifact_manifest.json` xác nhận đủ data, metrics, figures và video.

Các run `t007_*` là evidence lịch sử trước khi protocol được đổi tên thành
baseline. Giữ nguyên tên, metadata và kết quả của chúng để bảo toàn provenance.
