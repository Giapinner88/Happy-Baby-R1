# T004 — Calibration sensitivity

## Identity and scope

- **Study ID:** `t004`; **status:** executable.
- **Method:** [`docs/teleop/r1_arm_wrist_ik.md`](../../../../docs/teleop/r1_arm_wrist_ik.md).
- **Baseline evidence:** T003-A
  `t003_a_nominal_20260811T034825Z/waypoints.json`.
- **Manifest:** [`config/r1_t004_calibration_study.json`](config/r1_t004_calibration_study.json).

T004 is a deterministic mapper + IK study, not a live Quest or Isaac Lab
dynamics run. It treats the retained right-arm T003-A move waypoints as a
synthetic `quest_headset` source trace under identity calibration. The left
trace is an explicit Y-mirror of that source; it is not observed left-hand
telemetry. No result here covers transport latency, contact, self-collision,
controller tracking, hardware, or a real calibration procedure.

## Question and design

How do one-at-a-time calibration yaw and translation offsets change whether the
fixed T003 IK solver can solve every point in that trace for each arm?

The 22 declared cases are: identity baseline for left/right, yaw at −10°, −5°,
+5°, +10° for left/right, and ±30 mm along each of X/Y/Z for left/right. The
source trace, IK configuration, source orientation, zero base velocity and
continuous within-trace seed are fixed. The mapper transform is the accepted
yaw-then-translation transform; no scale factor is introduced.

The primary outcome is the declared IK screening rule: every waypoint converges
and none is clamped at a joint limit. It is deliberately not a hardware safety
margin. Secondary measures are maximum transformed-target displacement,
maximum IK position residual, and minimum reported joint-limit margin.

The study is invalid if the T003 source file is missing/malformed, a valid
synthetic mapper command is disabled, required run evidence is absent, or two
deterministic evaluations disagree beyond the declared repeatability tolerance.
Non-convergence or a clamp is a retained scientific failure, not an invalid
execution. A case table alone is inconclusive about live calibration accuracy.

## Execute

Run from repository root; no Conda environment, GPU, Quest, Isaac Lab or robot
is required:

```bash
python3 scripts/teleop/run_r1_t004_calibration_study.py --case-id all
```

Each case is allocated as a fresh `T004/runs/t004_<case-id>_<UTC>/` directory.
To repeat one condition, name it explicitly; the runner refuses to overwrite:

```bash
python3 scripts/teleop/run_r1_t004_calibration_study.py \
  --case-id right_yaw_pos10deg
```

Every case writes `trace.csv`, `case_metrics.json`, `verification.json`, a
resolved config, source-file hash, provenance and status. Editable run/case
selection belongs in [`metadata/`](metadata/README.md); durable summaries belong
in [`figures/`](figures/README.md). Analysis is a separate next artifact once
the matrix and status inventory are complete.

After exactly one run exists for every manifest case, make the complete study
table without filtering scientific failures:

```bash
python3 scripts/teleop/aggregate_r1_t004_calibration_study.py \
  --output-dir experiments/r1_teleop/quest3_sim_v1/T004/figures/<aggregate-id>
```

## Initial sweep outcome — 2026-08-11

The selected initial sweep is recorded in
[`metadata/initial_sweep_selection.json`](metadata/initial_sweep_selection.json)
and its complete table in
[`figures/t004_initial_20260811T044700Z/`](figures/t004_initial_20260811T044700Z).
The diagnostic figure is
[`calibration_sensitivity.png`](figures/t004_initial_20260811T044700Z/calibration_sensitivity.png).

Direct observations only: all 22 declared cases completed; all 22 traces
converged without a joint clamp; deterministic repeatability was zero joint
delta in every case. Across the selected cases, transformed target displacement
was 0–47.65 mm, reported minimum joint-limit margin was 0.08143–0.40520 rad,
and maximum position residual was 0.0978–0.1731 mm. Every case remains
`scientific_outcome: unassessed`: these facts do not establish a live calibration
accuracy or a hardware-safe region.

There is intentionally no T004 video: this study evaluates deterministic mapper
and IK geometry only, with no Isaac physics state or camera. The corresponding
per-run completeness records mark video as not applicable; T003 retains the
simulation videos for dynamic behavior.

The matrix/status and numerical repeatability checks are complete, so the next
artifact is a separate T004 analysis of the asymmetric margin changes and the
smallest discriminating follow-up range.
